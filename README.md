# 🛍️ Luxury E-Commerce Website

A modern, full-stack luxury e-commerce web application built with **Next.js, TypeScript, Tailwind CSS, and FoamSpree**.
This project showcases a premium shopping experience with dynamic product data, clean UI, and scalable architecture.

---

## 🚀 Features

* ✨ Modern UI/UX with responsive design
* 🛒 Product listing & detail pages
* 🧾 Dynamic product data from MongoDB
* 🛍️ Add to cart functionality (state management)
* 🔍 Category-based filtering
* ⚡ Fast performance using Next.js (App Router + Turbopack)
* 🎨 Styled with Tailwind CSS
* 🧩 Component-based architecture

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), React, TypeScript
* **Styling:** Tailwind CSS
* **Backend:** Next.js API Routes
* **FoamSpree:** FoamSpree
* **State Management:** Zustand
* **Icons:** lucide-react

---

## 📂 Project Structure

```
src/
 ├── app/                # Pages (App Router)
 ├── components/         # Reusable UI components
 ├── lib/                # Database connection
 ├── store/              # Zustand store
 └── styles/             # Global styles
```

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

---

### 2. Install dependencies

```
npm install
```

---

### 3. Run the development server

```
npm run dev
```

Open in browser:

```
http://localhost:3000
```

---

## 🔌 API Endpoints

### Get all products

```
GET /api/products
```

### Get product by ID

```
GET /api/products/:id
```

### Create product

```
POST /api/products
```
